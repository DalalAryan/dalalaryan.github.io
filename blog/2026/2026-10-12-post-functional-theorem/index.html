Hi! I’m Aryan, an undergraduate at UCLA studying mathematics and computer engineering. In this post, I discuss Post’s Functional Completeness Theorem (Emil Post, 1941). This post was mostly motivated by a question on my CS 181 Theory of Computation Problem Set:

(Boaz Barak Intro TCS Exercise 3.4) Prove that for every $n$-bit input circuit $C$ that contains only AND and OR gates, as well as gates that compute the constant functions 0 and 1, $C$ is \textit{monotone}, in the sense that if $x, x’ \in \left{0, 1\right}^n, x_i \leq x’_i$ for every $i \in \left[n\right]$, then $C\left(x\right) \leq C\left(x’\right)$. Conclude that the set $\left{\text{AND, OR}, 0, 1\right}$ is \textit{not} universal.

I was attempting this problem and thought about the universality of {AND, NOT} as well as {NAND} (one can show that {AND, NOT} is universal by using the universality of NAND and vice versa). In generally all cases of universality of gate sets, some form of negation ($\neg$) is incorporated even if not explicitly stated in the function definition. For exmaple, the gate set $\mathcal{F} = \left{\implies, 0\right}$ is universal even though NOT is not explicitly used. However, one can easily deduce that the following holds: $a \implies 0 = \neg a$. The negation appears both explicitly and implicitly in many such cases of universality of gate sets and I was curious as to whether negation was necessary for universality or if my observations were purely by chance. This led me to learn about Post’s Functional Completeness Theorem which I now discuss below!
